TeddyBox

Custom firmware for the ESP32 Toniebox. This page shows which boxes run it and helps to put audio on a tonie.

The setup page only answers while the box is in setup mode: Home Assistant button "Start setup", or hold the big ear while switching on.

Audio to tonie

Audio files are uploaded to teddyCloud's library, encoded there into one TAF file (one chapter per file, in name order) and set as the content of the tonie. The box downloads it the next time the tonie is placed or at the next check.

    On TeddyBox, a tonie whose file was uploaded on the setup page is protected and keeps it; switch the protection off there first.

    Live events

    What the boxes report to teddyCloud right now: tonie placed, ears, volume, playback. teddyCloud does not say which box sent an event.
